# OCR foundation and Home search — OCR-FOUNDATION-01

Scope: U-06 on the public v0.3.5 base `f56acb5`. The app can query visible album titles and stored creation/modification dates across the existing catalog pages. No private query is persisted or included in state diagnostics. The engine-neutral model distinguishes an empty recognition from failure, counts three starts including positively identified interruptions, retains same-input text on manual rerun, and requires a new owner-issued attempt ID for each claim. Its only synthetic recognition runs in JVM tests; it never supplies app search results.

Independent review initially returned 0 Critical, 2 Important and 3 Minor. The two Important issues were observed as JVM failures: an independently queued replacement accepted an obsolete token, and a displayed date did not match. The coordinator introduced claim identity and grouped date matching. Re-review found a third date defect, reproduced before binding a date and adjacent time to one actual timestamp. Both the retained scope label and diagnostic redaction have been corrected (the latter also failed before correction). Added tombstone/hidden-album and late noncooperative pagination regressions. A retained query may still need editing or clearing after a system time-zone change; automatic invalidation is deferred to the consuming omnibox/native pass. This receipt is not a re-review of the final clock correction or a device result.
