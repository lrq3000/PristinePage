## What the witnesses require

1. **Exact producer B, once.** The existing fixture freezes PNG page A, verifies the ordered assembly reference, and gives the shared render job one independently retained, normalized-equivalent JOB pin B. B is byte-distinct, encoded 2×3 with EXIF 6, normalized 3×2. At preflight the original PENDING metadata, no lease and no intent/READY must remain, and the port sees the exact B Source/Blob binding and the literal 1,048,602-byte ceiling. The scoped render port must receive that same binding object exactly once under a live owner and a fresh RUNNING lease. It reads B's small synthetic original through the supplied binding, supplies the actual request and 2×3 decode stage in a whole 3×2 result. The service forwards that result's live raster to both codec ports, commits the exact page, then closes raster and accounting owner before the scope ends. The real terminal metadata reader checks the persisted execution producer, journal, and READY row for B; the test separately checks final bytes, extent, and raster digest.
2. **Late pressure.** First preflight succeeds and actual acquisition reaches RUNNING; the synthetic renderer then returns `RESOURCE_LIMIT`, with no raster and a close probe. The service must close the whole refusal result, propagate the resource classification, never enter either codec port, and leave no READY, COMMITTED journal, SUCCEEDED job or new checkpoint. This does not prescribe a failure/recovery transaction or require rolling back a granted lease. Preflight approval is not a reservation.
3. **Readback refuses after owned intent.** Same-size, byte-different synthetic payload reaches the real limited `DerivedFiles` sink under a COPY grant, then the closed staged file reaches the verifier with the live raster and the same literal cap. The verifier accepts only the independent five-byte control (and returns the literal known raster digest), not a hash echoed from the render receipt. The adversarial payload refuses without READY or seal/move/commit, leaves the existing executor's unsealed staged evidence in COPYING, and closes the whole result. This is a forwarding/lifetime test, not another byte-limit stream unit case.
