## Method choice

Rotated retries cannot resolve mixed edge polarity. Global region thresholding still depends on background/interior separability. A library or general line-segment detector would add integration and packaging work but would still need the same page-boundary and false-crop decision. The existing regional detector already has a bounded line-voting structure; add a final local-contrast voting fallback for a dominant, approximately axis-aligned page. It combines luminance and opponent edge strength without forcing one sign across the four sides. Find shortlists of at most three candidates per side on the existing preview, refine near those lines, compare all four intersections and require support across each finite segment. Reject side continuations beyond a would-be cap, geometries without visible margins, and similarly supported distinct candidates. Do not change saved recipes, rendering math, source identity, dependency versions, or app memory budget.

Run `:core:test --tests '*MagazineGeometryTest' --tests '*AtelierEdgeDetectorTest'` for the short host gate. The Android method is `EditorComparisonScreenTest#fullBleedMagazineImportsSeedsRectifiesAndSavesWithoutAlteringTheOriginal`; compilation is not an LDPlayer result. Genuine curved-page reconstruction still requires independent evidence for the existing curved map path rather than treating a flat four-edge result as proof.

## Review controls and limits

Independent review exposed two false proposals in the new path: a clipped shadow cap with only one continued side, and a strong printed panel inside a weaker supported page. The reviewer controls, including a panel sharing one edge with its page, failed in JUnit before their safeguards were added. The fallback now vetoes an independently sustained continuation to the frame, and a fully supported enclosing candidate can veto an interior crop regardless of their contrast scores. It allows up to two analysis pixels of fit uncertainty at an enclosing edge and requires at least 20% additional area, to distinguish meaningful lost material from a nearby trim. Earlier RGB routes can still accept the two broader adversarial controls documented in `MagazineGeometryTest`; the direct fallback tests do not imply those pre-existing routes were repaired. Other controls include a different mixed-contrast synthetic sheet in both orientations and cancellation during the slope sweep.

The Android witness uses the real import service with a controlled provider stream, a real guided Compose seed, rotation and Apply through the session, and a database reopen of the accepted recipe and source. It renders the reopened recipe at full output size with export purpose and verifies retained color. It does not claim UI wizard progression, a real picker, or encoded file publication to an external provider.
