# Atelier — first native host checkpoint

The Android launcher now presents the Atelier library and page grid over the existing private catalog and editor. The four sorts use stored dates and locale collation across pages; title changes use the repository's revision check. The editor offers a viewport and tool ribbon with rotation, shape controls, real classical rendering and source comparison. Thumbnails are explicitly original previews. The existing camera/gallery/files behavior is retained via a sources sheet; the `+` is **not** yet the direct camera-to-mixed-draft journey. No demo image or fake correction substitutes for real app-owned data.

The confirmed product language is English for app-owned UI and accessibility, even on a French device. The original French mockup is a historical design reference, not an Android translation. Provider UI and user-authored titles are unchanged.

**Independent review dispositions:** Enforced the title input bound before it reaches saved state; kept the modal from hiding during a rename and added a selected-album reload/retry on conflict; kept a bounded card when an album cannot expand its page metadata; canceled superseded reads and used a raw-guarded chunked Room projection; restored the recipe-independent large original fallback on editor load failure.
