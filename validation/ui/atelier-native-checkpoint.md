## Storage reentry

The 30-case host SQLite group passed without storage changes. A separate in-memory check used the current `hiddenCount` query and migration: two abandoned staging documents, each with one canceled item and one untouched `INTENT` journal, returned two charged slots, the threshold at which `RoomAtelierDrafts.create` refuses another draft. The test did not create or remove any payload. A committed abandoned original, a failed copy that wrote bytes and an intent that never wrote bytes all need different evidence; the present query intentionally charges them alike.

Proposed first step, not implemented: reconcile only exact terminal attempts whose authenticated journal/lease and recorded paths prove that no payload was created and no producer can create one later. Preserve the journals, receipts, original paths and source/history pins. Do not equate canceled, expired, no seal, or not found by directory scan with that proof. Any actual retained bytes remain charged. A separate recovery and retention policy is needed for abandoned drafts containing originals; this narrow step would not free those slots or authorize deletion.

## Native reentry

Reclaim only the assigned emulator under the authorized shared allocator. A live local ADB server reporting the expected protocol and a stopped matching console row do not prove an authenticated guest path or safe unattended startup. The previous two attempts timed out before installation. Require explicit supervised readiness on the exact assigned instance, without device enumeration or shared server repair; then independently verify the two current APK hashes, approved development certificate and actual installed identities before using the prepared witnesses. Use only synthetic or locally cleared images. Release the owned emulator only after verifying that its player and VM exit. No current Android runtime work or shared ADB mutation is recorded by this checkpoint.

Keep native source out of public `main` and the exact archive until the applicable reviewed acceptance gates pass. Do not advance `main` merely because host compilation succeeds.
