## Intent and implementation

Make manual deskew and flattening available on the current album page without adding another rendering or persistence path. The default editor's Shape section now offers **Use whole image**, **Perspective** with four labeled corners, and **Manual curve** with additional top/bottom on-curve midpoint controls. Select the label then use horizontal and vertical sliders in one-percentage-point steps in the oriented original's axes. The sliders support keyboard/accessibility progress actions and have a 48dp minimum layout height. This is the numeric control POC, not an on-image drag handle, magnifier, synchronized zoom, advanced curve depth UI, or detection feature.

Perspective starts at the whole-image corners; switching to Manual curve keeps the quad and target rule and starts with the recipe's exact chord midpoints. When moving a corner in Manual curve, an exactly straight midpoint follows the chord; an explicitly adjusted point stays at its source position. Returning to Perspective drops the curve controls and keeps the quad; reset selects `None`. All shape changes preserve source binding, oriented dimensions, output quarter turns, and all appearance/finishing fields; they go through the existing recipe history for undo/redo. Preview sizing, homography, curved-map validation and resampling are the established code paths, not UI approximations.

`PreviewScheduler` still owns the only published result/bitmap and verifies full request equality (including generation, output and recipe) and actual raster dimensions. A sizing refusal now cancels the superseded request, keeps only a previous same-page/source pair, and publishes no new request. The UI labels retained pixels as previous, shows typed sizing/invalid-map or other render failures, and explains why Apply is unavailable. One guarded session save path covers both Apply and Apply-and-exit: for a shape different from the persisted shape, require a current OK Result for the retained page/source/revision and every field of the current draft. Pending, failed, stale and comparison requests do not qualify; even byte-identical `Input after shape` cannot authorize save. Return to Result for fresh proof. Legacy Looks-only and quarter-turn-only Apply behavior is preserved when the underlying shape is already saved. Repository CAS, durable recipe format, original bytes and other pages are unchanged by the implementation.
