# OCR job pack identity — OCR-JOB-06

The versioned input binds the exact ordered language codes and SHA-256 values supplied by the future installed-pack owner. The core configuration takes an immutable snapshot. A change of order or of one file's bytes changes the job digest; a v1 row is not accepted as v2. V1 remains byte-identical for the earlier engine-neutral tests. Existing jobs and private text are not rewritten.

The independent v2 fixture is 429 ASCII bytes with SHA-256 `b1605df44ae36f68e89b42e11a31fdc1b63430d0a1fa63767956dbf13af7606f`. The focused pre-implementation Gradle run recorded missing-contract errors at both `:core:compileTestKotlin` and `:data:compileDebugUnitTestKotlin`; neither reached JUnit. The tests also check the order, immutable list, noncanonical inputs, duplicate codes, pack-count limits, changed digests and version mismatch.

Independent review found that the initial count check trusted a caller list's size before making its copy. A JVM witness against the initial compiled class admitted both zero and 33 entries when iteration disagreed with that size. The corrected copy checks the entries it actually retains and stops before taking a 33rd entry. The regression uses a deterministic size/iterator mismatch rather than a timed race. The v2 row test additionally changes a payload byte while leaving its key and digest alone, to exercise the exact-byte comparison.

During restart recovery, one interrupted build reported corruption of a generated KSP lookup table. After the earlier processes exited, strict offline `:core:test :data:testDebugUnitTest` passed with one worker and process-local `-Pksp.incremental=false`: 283 core and 788 data JVM tests, with zero failures, errors or skips. The direct JVM witness refused both invalid counts after the correction. No tracked build settings or unrelated caches were changed.

This slice supplies no database lookup or job producer. Before OCR can run, resolve and retain the actual installed pack bytes, read the bounded job from Room, verify the live page/result ownership, and reject anything other than the exact v2 binding. A changed binding needs a fresh generation rather than replacement at the same key. Retain the producing binding with the recognized text so a subsequent rerun or pack change cannot mislabel a previous result. No model acquisition, schema change, APK or device evidence is implied.
