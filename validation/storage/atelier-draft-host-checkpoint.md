# Atelier private drafts — host-only checkpoint

The additive Room v1→v2 migration retains the 22 existing entities. It adds one staging table and one unique staging-document index. Existing saved albums and ingest journals are neither rewritten nor reclassified. A draft and its private companion document are inserted together; ordinary library/editor reads and ordinary album/page edits exclude hidden staging IDs. The reserved batch ID is checked at selection/bind and final ingest, and changes to the draft state fence late callbacks. This stores acquisition, freeze, step/selection, thaw and abandonment metadata only. The app does not open the new draft flow, and this checkpoint cannot publish a staged album.
