# Public sources, rights and evidence boundaries

Source review snapshot:2026-11-06 with specification synthesis2026-11-14. Pinned revisions below identify inspected implementations, not a claim of latest main. Read the exact source/asset terms at acquisition; legal clearance and the final application license are not established by this package. Public visibility or a working download URL does not itself grant unrestricted reuse.

## Reuse before new infrastructure

Use Android's supported camera/picker/storage/sharing mechanisms and maintained numerical libraries. Reuse public permissive source modules where they fit and preserve notices; isolate direct copyleft integrations in a distribution compatible with their terms. Prefer source-resampling geometry and simple parameter fields when their measured fidelity/resource fit is adequate. Do not create a new training project, remote service, generic workflow platform or mandatory model-conversion matrix merely to implement a few useful alternatives.

The important integrated capability is controllable local capture-to-export with explicit algorithms and truthful provenance. This package makes no novelty, patentability, benchmark-win, forensic-authenticity or universal-quality claim. Several parts are established methods; their fit and combined behavior must be measured in this product.

| MMDIR / D2Dewarp | Inspected README declares non-commercial-research CC BY-NC-ND4.0 wording | Not default product assets; no separately verified permissive model grant. Do not present research-restricted as equivalent to permissive open-source. |
| OpenCV | Versions4.5.0+ Apache-2.0; earlier BSD-3-Clause per official page | Audit the actual Android binary and bundled third-party notices. |
| ONNX Runtime / LiteRT and Android components | Inspect exact selected versions/licenses at bootstrap | Packaging/runtime/operator/ABI notices remain independent of a model's license. No cloud/Play-services dependency is allowed by the app's offline requirement. |

GPL software can be used commercially when its obligations are satisfied; “copyleft” is not “non-commercial.” Conversely, a research-only/NC restriction is not erased by an MIT wrapper. Training dataset use, texture-generation provenance and in-app sample display rights are distinct from model inference/distribution rights. Keep the default release allowlist permissive-or-otherwise-explicitly-approved; leave the overall application license open until selected by its owner.

## Required asset/dependency record

For each adopted artifact retain official origin, immutable revision/release, acquisition date, file hashes, source/weight/data/license categories separately, notice text/location, dependencies, redistribution/modification conditions, approved build variants, reviewer and unresolved questions. For a model add input/output contract, conversion/runtime/backend/precision, parity and device evidence. For gallery images add origin/creator/display rights and actual algorithm-output manifest. Dependency updates and changed assets reopen affected rights/parity gates.
