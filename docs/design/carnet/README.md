# Carnet — Android visual direction

The approved visual reference is **A — Carnet** in the [original interactive mockup](../../superpowers/mockups/first-major-redesign.html). Use its ivory background (`#F8F8EF`), warm paper (`#FFFDF4`), ink (`#182D24`), forest accent (`#244F3E`), sage selection (`#E2EBD3`) and 17dp surface rounding. Use the Android system serif for the large Home heading, a circular Home capture shortcut, and a dark camera viewfinder as in the reference. Noninteractive decorative borders use muted sage; interactive outlines must remain visible against paper. Keep the real camera controls and existing folded-page icon.

**Settings → Home and albums → Home thumbnails** offers **Stack** (default; up to three overlapping saved pages) and **Row** (all saved pages in a horizontal scrolling strip). Both follow album page order. A visible row tile uses the same revision-checked renderer as the stack and the album grid. Loading/unavailable content must not masquerade as an original or a saved thumbnail. The layout choice is local to Home, survives restart, and does not change album order, navigation, or previous settings.

A second complete theme would duplicate UI decisions and a palette-only swap would omit the serif heading, circular capture shortcut and thumbnail geometry. The selected approach adapts the existing native Compose screens. The [Atelier contract](../../specs/ATELIER.md) remains the functional authority; Carnet supersedes presentation only, including for Home, settings, capture, review, wizard, page editor and batch. Keep input data, processing, permissions, labels, accessibility, and persistence contracts except for the new independent preference.
